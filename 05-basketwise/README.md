# BasketWise — рекомендации товаров

Независимый локальный проект React/TypeScript + FastAPI. PL/EN-интерфейс с реальными рекомендациями из сохранённых матриц. Это исследовательская демонстрация, не интернет-магазин. Названия товаров — исходные английские названия каталога; цены — исторические GBP.

## Запуск

Python 3.12 и Node.js 24. Из этой папки:

```powershell
.\setup.ps1
.\run.ps1
# http://127.0.0.1:8105
```

Можно изменить порт: `.\run.ps1 -Port 8205`. Остановка: Ctrl+C. Веса уже включены; обучение для просмотра не нужно. После установки демо работает офлайн. Среда .venv не переносится — повторите setup на новом компьютере.

```powershell
.\train.ps1
.\evaluate.ps1
.\.venv\Scripts\python.exe -m pytest tests -q
```

Обучение перезаписывает артефакты. evaluate только пересчитывает сохранённые модели/выборки, допустимое расхождение 1e-8; отчёт — reports/reproduction.json.

## Протокол

UCI Online Retail, 2010–2011. Удаляются отмены, неположительные цены/количества, строки без CustomerID/описания. Уникальные дни разделены 70/15/15 по времени. Только train формирует каталог и матрицы: 1600 наиболее популярных товаров минимум с пятью покупателями. Пользовательские взаимодействия бинарные.

Модели: популярность, cosine item-item, TruncatedSVD (48 компонент). Выбор по validation NDCG@10. Оценка на полном каталоге, без sampled negatives. Уже купленные товары исключены; релевантные ответы — будущие, новые для пользователя товары известного каталога. Для неизвестного пользователя отдельный popularity fallback и отдельные cold-start метрики. Все test predictions используют замороженную train-историю, без добавления покупок из validation.

Снижение покрытия каталога и ограниченность warm-user оценки явно отражены в model card. Показатели Recall@10/NDCG@10 не равны конверсии или росту выручки. Иллюстрации категорий в UI — векторные символы, не фотографии исходных товаров.

## API

- `GET /api/v1/meta`: метрики, методология, демонстрационные истории.
- `GET /api/v1/catalog?q=HEART&limit=24&offset=0`: поиск, максимум 100 результатов.
- `POST /api/v1/predict`: `{ "items": ["85123A"], "k": 8 }`, до 100 входных ID и 20 рекомендаций. Неизвестные ID отклоняются.
- `GET /api/v1/report`: CSV метрик; `/api/v1/openapi.json`: схема; `/api/v1/health`: состояние.

Все веса находятся в artifacts/weights.npz; выборки, каталог, конфигурация, checksums и метрики включены. Исходный архив в data/. Нет зависимостей от соседних папок или внешнего inference API.
