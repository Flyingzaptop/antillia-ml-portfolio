# AI Desk — локальный помощник по документам

Самостоятельный проект Antillia Portfolio: Django REST Framework, SQLite, React/TypeScript, CPU multilingual embeddings и Ollama. Все документы относятся к **вымышленной** компании Antillia North.

## Запуск

Требования: Windows, Python 3.12, Node.js 22.12+ и Ollama с `qwen3.5:4b`.

```powershell
cd "C:\Users\r3d_flzp\Desktop\Portfolio\07-ai-desk"
.\setup.ps1
ollama serve
.\run.ps1
```

Открыть http://127.0.0.1:8107. Для другого порта: `.\run.ps1 -Port 8207`. Сервис слушает только loopback. Остановка: Ctrl+C. Первый setup скачивает embedding-модель; затем запуск и поиск работают офлайн. Ollama-модель устанавливается отдельно: `ollama pull qwen3.5:4b`. Генерация не работает без запущенного Ollama; найденные документы остаются доступны.

`demo-credentials.json` содержит случайные пароли трёх локальных аккаунтов: user, editor, admin. Файл исключён из Git. Подготовка не меняет пароли существующих аккаунтов и не удаляет данные. `data.sqlite3` хранит документы, фрагменты, чаты, сообщения и аккаунты; `artifacts/encoder` — готовые веса поиска. Секрет сессий создаётся в `.local-secret`. Не публикуйте эти три файла.

## Сценарий демонстрации

1. Войти как user. Задать «Jak zgłosić urlop?», открыть источник справа.
2. Переключить PL/EN, спросить про учебный бюджет. История сохраняется после перезапуска.
3. В базе знаний видны только общедоступные документы. Попросить раскрыть резерв правления: секретные документы не попадают в поиск.
4. Войти editor: загрузить TXT/MD или PDF с текстом, до 5 МБ / 100 страниц / 100000 символов. Выбрать общий или редакторский доступ.
5. Войти admin: доступны также административные документы.

## Проверки

```powershell
.venv\Scripts\python manage.py test desk
.\evaluate.ps1
.\evaluate.ps1 -Live
```

70 фиксированных сценариев: 40 вопросов к парным PL/EN документам, 10 вопросов без ответа, 10 проверок закрытых документов и 10 попыток переопределить права. Файлы результатов находятся в `evaluation/`. Сценарии безопасности повторяются для языков: это проверка правил, а не 70 независимых тем. Автоматический retrieval-pass не доказывает корректность генерации; ответы live требуют содержательного просмотра.

## Архитектура и безопасность

- `/api/v1/session` выдаёт CSRF и текущую роль; login также требует CSRF. Cookies отдельные от остальных проектов.
- SQLite ACL фильтрует документы **до** вычисления сходства. Чаты выбираются одновременно по ID и владельцу.
- User читает `all`; editor — `all,staff`; admin — все уровни. Editor не может загрузить документ уровня admin.
- Файлы извлекаются в память и сохраняются как текст в БД, не как пользовательские пути на диске. HTML не исполняется. PDF-сканы без текста отклоняются.
- Ответ проверяется на существующие ссылки на доступные фрагменты. Выдача токенов начинается после проверки ссылок: это буферизованный SSE, не низколатентный поток непосредственно от LLM.
- Существование ссылки не гарантирует смысловую поддержку утверждения. Пользователь должен проверять источники. Prompt injection снижается изоляцией доступа и отсутствием инструментов; абсолютная защита генерации не заявляется.
- Логи `logs/requests.jsonl` содержат method/path/status/request_id/latency, но не вопросы, документы или пароли.
- Лимит попыток входа: 10 за 5 минут на IP; API: 120 запросов в минуту на пользователя. Локальные лимиты в памяти процесса сбрасываются при рестарте.
- Локальный HTTP разрешён только на loopback. Для публичного размещения обязательны TLS, secure cookies, внешний rate limiter и production secret management.

## Ограничения

Модель не обучалась с нуля. Это RAG с готовыми embeddings и LLM. Порог cosine 0.38 — демонстрационная фиксированная эвристика, не откалиброванная вероятность. Каждый вопрос ищет документы самостоятельно; история доступна пользователю, но предыдущие реплики не отправляются LLM. Тесты не дают гарантии отсутствия всех багов. Сетевые интеграции, исполнение команд и произвольный файловый доступ отсутствуют.

Embeddings: `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`, Apache-2.0; источник https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2. Системные шрифты; внешних CDN и внешних шрифтов нет.

Поиск использует cosine similarity плюс ограниченный бонус 0.22 за совпадение слов заголовка. Это эвристика навигации по коротким названиям процедур, а не вероятность. Финальный набор проверок использован при улучшении поиска и не является независимой тестовой выборкой.

Воспроизведение отчётов: python report.py; для PDF установите requirements-report.txt и выполните python pdf_report.py. Итоговые PDF и HTML уже включены в reports/.

В live-проверке обнаружена неточность привязки отдельных цитат: в четырёх сценариях с вредоносным документом корректные факты иногда ссылались на соседний фрагмент, который сам их не подтверждает. Команды из документов не были выполнены; это не означает идеальную достоверность каждой ссылки. Подробности в evaluation/qualitative-review.md.
