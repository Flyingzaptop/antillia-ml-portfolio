# DemandCast — прогноз спроса на 24 часа

Самостоятельное локальное ML-приложение: React/TypeScript + FastAPI. Интерфейс PL/EN, польский по умолчанию. Данные исторические, это не прогноз текущего движения в Вашингтоне.

## Запуск Windows

Нужны Python 3.12, Node.js 24 и npm. Из этой папки:

```powershell
.\setup.ps1
.\run.ps1
# http://127.0.0.1:8101
```

Готовые веса находятся в `artifacts/`, обучение для просмотра не требуется. Остановка: Ctrl+C в окне сервера. Другой порт: `.\run.ps1 -Port 8201`. После подготовки проект работает без интернета. Не переносите `.venv` между компьютерами; выполните setup заново.

## Обучение и воспроизведение

```powershell
.\train.ps1
.\evaluate.ps1
.\.venv\Scripts\python.exe -m pytest tests -q
```

`train.ps1` заново готовит фиксированные выборки и перезаписывает артефакты. Перед экспериментами сохраните исходную папку artifacts. `evaluate.ps1` не обучает модели: пересчитывает validation/test из сохранённых весов и проверяет расхождение <= 0.0001. Результат — `reports/reproduction.json`.

## Метод

168 часов истории → 24 часа прогноза. Данные делятся хронологически 70/15/15. Пропуски истории заполняются предыдущим наблюдением; окна с отсутствующими целевыми значениями исключаются. Тестовые окна идут с шагом 24 часа. Используются только известный календарь и прошлые количества; будущая погода, casual/registered и будущие counts исключены.

Модели: сезонный naive (та же неделя/час), HistGradientBoostingRegressor, обученная GRU. GRU использует нормализацию по тренировочным историям, Adam и остановку по validation MAE. Победитель выбирается исключительно по validation MAE. В этом запуске выиграл сезонный baseline; слабые результаты GRU не скрываются. Обучение — CPU, без внешних API.

## API и файлы

- `GET /api/v1/meta`: измеренные метрики, временные границы, доступные origins.
- `POST /api/v1/predict`: `{ "origin_index": 0, "history_scale": 1.0 }`; возвращает историю, 24 прогноза всех моделей и наблюдения.
- `GET /api/v1/report`: CSV метрик; `GET /api/v1/openapi.json`: схема.
- `GET /api/v1/health`: проверка готовности.
- `artifacts/split_manifest.json`: границы, origins, source SHA256.
- `reports/metrics.csv`, `predictions.csv`, `artifact_hashes.json`: проверяемые результаты.

Изменение масштаба истории — условный сценарий, не проверенный causal effect. Сравнительные метрики всегда относятся к исходной истории. Предсказания не имеют заявленного доверительного интервала. Результаты на одном городе и историческом периоде не доказывают перенос на другой рынок.
