# ReviewPulse

Самостоятельный ML-проект Antillia. Интерфейс PL/EN (по умолчанию PL), настоящий локальный inference, собственный FastAPI и сохранённые веса. Данные пользователя не отправляются в облако.

## Запуск на Windows

Требуются Python 3.12, Node.js 22.12+ (проверено на Node 24), PowerShell. Первоначальная установка требует интернет; подготовленный inference работает офлайн.

```powershell
cd "C:\Users\r3d_flzp\Desktop\Portfolio\06-reviewpulse"
.\setup.ps1
.\run.ps1
# http://127.0.0.1:8106
# альтернативный порт: .\run.ps1 -Port 8200
```

Остановка: Ctrl+C. Сервер привязан только к localhost. Здесь нет пользовательских аккаунтов и постоянного хранения запросов: это stateless ML-демо, не банковская система. Публичное развёртывание требует TLS, аутентификации и ограничений на уровне reverse proxy.

## Обучение и воспроизведение

```powershell
.\train.ps1
.\evaluate.ps1
.\.venv\Scripts\python.exe -m pytest tests -q
```

`train.ps1` обучает TF-IDF + logistic regression и два варианта MLP на замороженных многоязычных embeddings. Обучение CPU, максимум 2 потока, seed 42. `evaluate.ps1` загружает сохранённые веса и неизменные split-файлы, пересчитывает результаты. Временные измерения закономерно меняются; предсказания и метрики — детерминированные с допуском 1e-6. Оба скрипта перезаписывают результаты эксперимента. Архивируйте предыдущие отчёты перед переобучением.

`data/splits.json` содержит тексты, метки, SHA256 идентификаторы и фиксированные train/validation/test. Дубликаты нормализованного текста удалены до разделения. Векторизатор и классификаторы обучены только на train. Validation выбирает модель, регуляризацию и порог отказа; test не используется для выбора. Кэш embeddings относится к этим split-файлам; при изменении данных удалите соответствующие `data/*_embeddings.npy` перед обучением.

## API

- `GET /api/v1/health`: 200 ready или 503 unavailable.
- `GET /api/v1/meta`: настоящие метрики, параметры и примеры.
- `POST /api/v1/predict`: JSON `{"text":"Your message"}`, 3–2000 символов.
- `POST /api/v1/batch`: multipart `file`, UTF-8 CSV с колонкой `text`, до 100 строк, 1 MB.
- `GET /api/v1/report`: HTML отчёт.
- `GET /api/v1/metrics`: JSON результаты.
- `GET /api/v1/sample.csv`: пример импорта.
- `/docs`: OpenAPI (интерактивная Swagger UI требует CDN; JSON `/openapi.json` доступен офлайн).

Ответ содержит `results`, `model`, `elapsed_ms`, `threshold`; у каждого результата — `label`, `confidence`, `uncertain`, `top`. В confidence показана некалиброванная оценка классификатора, не гарантия правильности. Порог отказа выбран на validation. Нет обученной категории out-of-domain: даже уверенный ответ на посторонний текст может быть неверным.

## Артефакты

- `artifacts/encoder/`: полная локальная копия multilingual MiniLM, без сетевых обращений при inference.
- `artifacts/*.joblib`: доверенные локальные веса (никогда не загружать сторонние pickle/joblib).
- `artifacts/training.json`: конфигурация, версии, длительность обучения.
- `reports/metrics.json`, `metrics.csv`, `report.html`: реальные результаты, матрица ошибок, классификационный отчёт и примеры ошибок.
- `reports/checksums.json`: SHA256 данных и весов.
- `data/polish_control.json`: небольшой авторский диагностический PL-набор; не независимый benchmark, не использован для выбора модели.

## Ограничения

Модель бинарная: positive / negative. Нейтральный класс не обучался. UCI содержит отзывы о товарах, фильмах и ресторанах. Сарказм, смешанная тональность и смена домена могут приводить к ошибкам. Междоменный перенос в отчёте — отдельная logistic regression по embeddings, обученная только на других доменах train.

Результаты — собственный воспроизводимый эксперимент, не внешняя сертификация. Прогнозы не используются для принятия финансовых решений. В логах только request ID, путь, код ответа и длительность; тексты запросов не записываются. Ограничения CSV/JSON проверяются сервером. Загруженные файлы не сохраняются и не исполняются.
